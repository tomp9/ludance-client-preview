# LuDance Client Preview

Static presentation demo for the LuDance website proposal.

This repository is intentionally separate from the private `ludance-theme` and `ludance-core` repositories. It contains presentation-only HTML/CSS/JS and no WordPress, PHP, business logic, payments, reservations, or production data.

## Visual direction

The demo follows the approved **Industria probada** composition. The layout is treated as the stable approved proposal; copy, images, classes, teachers, schedules, events, metrics and CTAs are replaceable.

## Deployment

Intended for GitHub Pages. The production implementation remains the private WordPress theme and `ludance-core` project.
